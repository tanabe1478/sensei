# /today — 今日の学習焦点

## 概要
学習セッションの開始時に、今日取り組む焦点を1つ決めるスキル。
認知負荷理論に基づき、1回に扱うテーマを絞る。

## 動作

### 1. 前回の学習状態を確認
- workspace/projects/{project}/logs/ から最新ログを読む
- 前回の `nextHypothesis`（次に確かめる仮説）があればそれを提示

### 2. ユーザーに焦点を聞く（代行抑制）
**重要**: AIが焦点を決めるのではなく、まずユーザーに聞く。

提示テンプレート:
```
📌 前回の学習（{日付}）:
  学んだこと: {learned の要約}
  まだ曖昧: {unclear の要約}
  次の仮説: {nextHypothesis}

今日は何に取り組みますか？
```

前回ログがない場合:
```
📌 このプロジェクトの学習は初回です。
今日は何に取り組みますか？
```

### 3. 復習リマインド
今日の復習対象アイテムがある場合、件数を通知:
```
📝 復習対象が {N}件 あります。/review で確認できます。
```

## 引数
- `project`: プロジェクト名（省略時はデフォルトプロジェクト）

## 設計原則
- **代行抑制**: 焦点を AI が決めない。提案はするが最終決定はユーザー
- **認知負荷管理**: 焦点は1つに絞る
- **間隔反復との連携**: 復習対象があれば通知
