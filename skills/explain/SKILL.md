# /explain — 自己説明促進

## 概要
最近の実装や学習に対して「なぜ？」を投げるスキル。
Self-Explanation Effect を活用し、因果理解を深める。

## 動作

### 1. 対象の選択
以下のいずれかから対象を選ぶ:
- 最新の学習ログの設計判断
- 直近の Git コミット
- ユーザーが指定したトピック

### 2. 質問の投げかけ
```
🔍 自己説明チャレンジ

「{対象の判断や実装}」について:

1. なぜこの方法を選びましたか？
2. 他にどんな選択肢がありましたか？
3. それらを選ばなかった理由は？

---
⚠️ 資料を見ずに、自分の言葉で説明してください。
```

### 3. 深掘り
ユーザーの回答後、1つだけ追加質問:
```
🤔 もし {前提条件} が変わった場合、同じ選択をしますか？
```

### 4. 記録
説明内容を学習ログに追加。理解が深まった点は復習アイテムに反映。

## 引数
- `project`: プロジェクト名
- `topic`: 説明対象（省略時は最新ログから）

## 設計原則
- **因果の追求**: 「何をしたか」ではなく「なぜそうしたか」
- **代行抑制**: AI は質問するだけ。説明はユーザー
- **単なる言い換え防止**: 他の選択肢との比較を求める
