# /setup-notifications — 学習通知セットアップ

## 概要
学習支援に必要な定期通知をスケジューラに登録するセットアップスキル。

## 推奨スケジュール

以下のスケジュールを `/schedule add` で登録する:

### 朝の復習通知（毎日 9:00）
```
/schedule add 毎日 9:00 今日の復習対象を確認してください。/review で確認できます。
```

### 夜の学習ログリマインド（毎日 21:00）
```
/schedule add 毎日 21:00 今日の学びを /log で記録しませんか？
```

### 週次振り返り（毎週日曜 10:00）
```
/schedule add 毎週日曜 10:00 今週の学習進捗を /progress で確認しましょう。
```

## 動作
このスキルが実行されると、ユーザーに上記の推奨スケジュールを提示し、
登録するかどうかを確認します。

## 注意
- スケジュールは sensei の scheduler を使用
- 通知先チャンネルは現在のチャンネルまたは REVIEW_NOTIFY_CHANNEL
- タイムゾーンは Asia/Tokyo
