# /recall — 想起練習

## 概要
過去に学んだ内容からランダムに1つ選び、資料を見ずに説明を求めるスキル。
Retrieval Practice（想起練習）の効果を活用し、長期記憶への定着を促す。

## 動作

### 1. 出題
復習アイテム（reviews.json）からランダムに1つ選び、問いかける:

```
🧠 想起練習

以下のトピックについて、資料を見ずに説明してください:

「{topic}」

ヒント: {content の一部（最初の20文字程度）}...

---
⚠️ まず自分で説明してから、回答を送信してください。
```

**代行抑制**: ユーザーの回答が来るまで、AIは答えを出さない。

### 2. フィードバック
ユーザーの回答後、記録された内容と照合して簡潔なフィードバック:

```
📊 フィードバック

あなたの説明: {要約}
記録されていた内容: {content}

{差分や補足があれば簡潔に}

この想起の難易度はどうでしたか？
  5️⃣ 完璧に思い出せた
  4️⃣ 少し迷ったが正しかった
  3️⃣ ヒントで思い出した
  2️⃣ かなり助けが必要だった
  1️⃣ ほぼ思い出せなかった
  0️⃣ 全く思い出せなかった
```

### 3. SM-2 更新
ユーザーの自己評価（0-5）に基づき、SM-2 アルゴリズムで次回復習日を更新:

```
📅 次回復習: {nextReview の日付}
   （間隔: {interval}日）
```

### 4. 記録
想起練習の結果を recalls/{date}.json に追加。

## 引数
- `project`: プロジェクト名（省略時はデフォルトプロジェクト）
- `topic`: 特定トピックを指定（省略時はランダム選択）

## 設計原則
- **代行抑制**: 回答はユーザーが先。AI は待つ
- **自己評価**: 難易度判定もユーザー自身が行う
- **間隔反復**: SM-2 で最適な復習タイミングを計算
