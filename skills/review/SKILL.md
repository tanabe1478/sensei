# /review — 復習セッション

## 概要
SM-2 アルゴリズムに基づき、今日復習すべきアイテムを一覧表示し、
順番に想起練習を行うスキル。

## 動作

### 1. 復習対象の表示
今日が期限の復習アイテムを一覧表示:

```
📋 今日の復習（{件数}件）

期限超過:
  🔴 {topic1} （{N}日超過）
  🔴 {topic2} （{N}日超過）

今日の復習:
  🟡 {topic3}
  🟡 {topic4}

/recall で1つずつ復習しますか？
それとも一覧だけ確認しますか？
```

### 2. 連続復習モード
ユーザーが復習を開始したら、期限超過 → 今日分の順で /recall を実行。
1件ごとに:
1. トピックを出題（資料なし）
2. ユーザーの回答を待つ
3. フィードバック
4. 難易度の自己評価（0-5）
5. SM-2 で次回復習日を更新
6. 次のアイテムへ

### 3. セッション終了
全アイテム完了後:
```
✅ 復習完了！

今日の結果:
  完璧(5): {N}件
  正解(3-4): {N}件
  要復習(0-2): {N}件

明日の復習予定: {N}件
```

### 4. 復習アイテムの管理コマンド
- `/review list`: 全復習アイテム一覧
- `/review add {topic} {content}`: 手動追加
- `/review remove {id}`: 削除

## 引数
- `project`: プロジェクト名（省略時はデフォルトプロジェクト）
- `list`: 一覧表示のみ
- `add`: アイテム追加
- `remove`: アイテム削除

## 設計原則
- **間隔反復**: SM-2 アルゴリズムで最適な復習間隔
- **想起練習**: 各アイテムで /recall と同じ流れ
- **代行抑制**: 答えは常にユーザーが先
- **期限超過優先**: 遅れているアイテムを先に処理
