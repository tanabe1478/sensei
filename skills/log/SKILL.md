# /log — 学習ログ記録

## 概要
作業終了時に、今日の学びを構造化して記録するスキル。
自己説明（Self-Explanation）と想起練習（Retrieval Practice）を組み込む。

## 動作

### 1. 対話形式で記録を促す
以下の質問を順に投げかける。**AIが代わりに書くのではなく、ユーザー自身の言葉で書かせる。**

```
📝 今日の学習を記録しましょう。

1️⃣ 今日わかったことは何ですか？
   （箇条書きで）
```

ユーザーの回答後:
```
2️⃣ まだ曖昧な部分はありますか？
```

```
3️⃣ 設計上の分岐があれば教えてください。
   なぜその選択にしましたか？（← 自己説明）
```

```
4️⃣ 次に確かめたい仮説は何ですか？
```

### 2. 自己説明の深掘り
設計判断について1つだけ深掘り質問を追加:
```
🤔 「{ユーザーの設計判断}」について、
   他の選択肢はなぜダメだったのですか？
```

### 3. 記録を保存
以下の形式で workspace/projects/{project}/logs/{date}.json に保存:

```json
{
  "date": "2026-03-11",
  "focus": "今日の焦点",
  "learned": ["学んだこと1", "学んだこと2"],
  "unclear": ["曖昧な点1"],
  "designDecisions": ["判断とその理由"],
  "nextHypothesis": "次の仮説"
}
```

### 4. 復習アイテムの自動生成
「今日わかったこと」から、復習用の問いを1〜2件自動生成し、reviews.json に追加:
```
✅ 復習アイテムを追加しました:
  - 「{topic}」→ 明日復習予定
```

## 引数
- `project`: プロジェクト名（省略時はデフォルトプロジェクト）

## 設計原則
- **自己説明**: 「なぜその選択か」を言語化させる
- **想起練習への接続**: 学びを復習アイテムに変換
- **代行抑制**: AI は質問するだけ。要約や整理はユーザーがやる
