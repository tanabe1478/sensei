# /errors — 誤り台帳

## 概要
バグ、誤解、用語混同を分類・記録するスキル。
同じカテゴリの誤りが繰り返されたら警告し、復習アイテムに自動登録する。

## 動作

### /errors add — 誤り記録
```
📛 誤りを記録します。

1️⃣ カテゴリは？
   （例: アルゴリズム / 用語 / 設計 / 実装 / ツール）

2️⃣ 何を間違えましたか？

3️⃣ 原因は何でしたか？（分かれば）

4️⃣ どう解決しましたか？（分かれば）
```

→ errors/{id}.json に保存
→ 復習アイテムに自動追加

### /errors list — 一覧
```
📛 誤り台帳

カテゴリ別:
  アルゴリズム (3件):
    - {description1}
    - {description2}
    - {description3}
  用語 (1件):
    - {description}
```

### /errors check — 繰り返し警告
同じカテゴリに3件以上あれば警告:
```
⚠️ 「アルゴリズム」カテゴリの誤りが{N}件あります。
   集中的に復習することをお勧めします。
```

## 引数
- `project`: プロジェクト名
- `add`: 誤り追加
- `list`: 一覧表示
- `check`: 繰り返し警告チェック

## 設計原則
- **分類**: カテゴリ分けして傾向を可視化
- **復習連携**: 誤りを復習アイテムに自動登録
- **パターン検出**: 繰り返される誤りを検出して警告
